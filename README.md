# 🛡️ CloudGuard — Attack Surface Management (ASM) & Port Scanner

**CloudGuard** — це високопродуктивний асинхронний інструмент для моніторингу поверхні атак (**Attack Surface Monitoring**). Він дозволяє виявляти відкриті мережеві порти у діапазоні `1–65535`, проводити **Banner Grabbing** для визначення версій програмного забезпечення та автоматично оцінювати рівень ризику для кожного знайденого сервісу.

Проєкт розроблено розробником **dreamyr**.

---

## 🚀 Ключові можливості (Features)

* **Повне сканування портів:** Аналіз усіх **65,535 портів** цільового хоста.
* **Асинхронне сканування (`asyncio`):** Паралельна обробка мережевих з'єднань для високої швидкості роботи.
* **Banner Grabbing:** Отримання первинної відповіді від сервісу для визначення його назви та версії.
* **Автоматична оцінка ризиків:** Кожен знайдений сервіс отримує рівень ризику: `CRITICAL`, `HIGH`, `MEDIUM`, `LOW` або `INFO`.
* **JSON API:** Зручний REST API для запуску сканувань та отримання результатів.
* **Сучасний Web UI:** Простий веб-інтерфейс для взаємодії зі сканером.
* **Docker Ready:** Можливість швидкого запуску проєкту в ізольованому Docker-контейнері.

## 💻 Інструкція з запуску

### Спосіб 1. Локальний запуск (Python)

1. **Клонуйте репозиторій:**

   ```bash
   git clone https://github.com/your-username/cloudguard.git
   cd cloudguard
   ```

2. **Створіть та активуйте віртуальне середовище:**

   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```

   Для Windows:

   ```powershell
   python -m venv venv
   venv\Scripts\activate
   ```

3. **Встановіть залежності:**

   ```bash
   pip install -r requirements.txt
   ```

4. **Запустіть API-сервер:**

   ```bash
   uvicorn main:app --reload
   ```

5. **Відкрийте веб-інтерфейс:**

   Відкрийте файл `index.html` у своєму браузері.

API буде доступне за адресою:

```text
http://127.0.0.1:8000
```

---

### Спосіб 2. Запуск через Docker Compose

Для швидкого розгортання в ізольованому контейнері виконайте:

```bash
docker-compose up --build
```

Після запуску API буде доступне за адресою:

```text
http://127.0.0.1:8000
```

## 🔌 API

CloudGuard надає REST API для запуску сканування цільового хоста.

### POST `/api/v1/scan`

**Приклад запиту:**

```json
{
  "host": "scanme.nmap.org"
}
```

### Приклад відповіді:

```json
{
  "target": "scanme.nmap.org",
  "ip": "45.33.32.156",
  "overall_status": "WARNING",
  "findings": [
    {
      "port": 22,
      "service": "SSH",
      "risk_level": "MEDIUM",
      "description": "Віддалений доступ. Потрібен захист ключами або VPN.",
      "banner": "SSH-2.0-OpenSSH_7.4p1 Debian-10+deb9u7"
    }
  ]
}
```

## 📊 Рівні ризику

CloudGuard автоматично класифікує знайдені мережеві сервіси:

| Рівень | Опис |
|---|---|
| 🔴 `CRITICAL` | Критично небезпечний або потенційно вразливий сервіс |
| 🟠 `HIGH` | Високий рівень ризику |
| 🟡 `MEDIUM` | Потенційний ризик, який потребує перевірки |
| 🟢 `LOW` | Низький рівень ризику |
| 🔵 `INFO` | Інформаційний результат без явної загрози |
